Personality & Response Layer
24Narrative LayerComplete▶

Every artifact-mode tool call fires three spoken phases in sequence: acknowledge → bridge (repeating) → handoff.

Artifact path timing:
query → classify (artifact) → acknowledge spoken (<200ms from classify)
                             → background task starts
                             → bridge spoken every 8s while running
                             → task completes → handoff spoken
                             → result displayed in UI
  • Acknowledge: fires within <200ms of artifact classification. Spoken before any result exists. Defined in narratives.acknowledge YAML key per tool.
  • Bridge: spoken at 8s fixed interval (UCL-adaptive in future). List of options in narratives.bridge — one chosen randomly per interval.
  • Handoff: spoken when task completes. Template fill from tool result in v6 v1 — narratives.handoff contains a string with {result} placeholder. PERS-2 narration is design-only, feature-flagged off (FEATURE_PERS2 = False).
  • Failure: spoken if task errors. Defined in narratives.failure YAML key.
  • Tool YAML example: 
    name: finance_summary
mode: artifact_only
narratives:
  acknowledge: "Let me check your finances."
  bridge:
    - "Still pulling that together…"
    - "Almost ready…"
  handoff: "Here's your summary: {result}"
  failure: "I couldn't retrieve that right now."
  • UCL events: narrative.ack (tool_name, latency_ms), narrative.bridge (tool_name, bridge_count), narrative.handoff (tool_name, total_duration_ms)
