Infrastructure Layer
05Hardware Detection & Capability TiersComplete▶

A hardware profile is generated once on application startup to assign the host to Tier 0, 1, or 2, which dynamically gates local model allocation and routing.

  • Hardware Tier Definitions:
    • Tier 0 (Low VRAM/CPU-only): < 8 GB VRAM. Whisper base STT (int8 CPU) and Kokoro TTS on CPU. All LLM inference (conversational and artifact paths) routes to cloud (Anthropic).
    • Tier 1 (Mid VRAM): 8 GB to 20 GB VRAM (e.g. RTX 3060 12GB, Apple M-series with 16GB+ unified RAM). Whisper small STT (float16 GPU) and Kokoro TTS. Conversational LLM runs locally (8B model); artifact-mode LLM routes to cloud.
    • Tier 2 (High VRAM): ≥ 20 GB VRAM. Whisper small STT and Kokoro TTS. All LLM inference (conversational and artifact paths) runs locally.
  • Detection Mechanisms:
    • Windows/Linux (NVIDIA): subprocess query to nvidia-smi --query-gpu=memory.total --format=csv,noheader,nounits with a strict 1000ms execution timeout, parsing VRAM directly in MB.
    • macOS (Apple Silicon): Unified memory size query via sysctl hw.memsize. Unified memory behaves as both system memory and VRAM.
    • System RAM: psutil.virtual_memory().total to verify minimum memory availability (16GB required for local LLM execution in Tier 1+).
  • Detection Timing & Scope: Runs once during the early boot sequence (before the databases or UI are initialized). The result is stored as an immutable CapabilityProfile dataclass in the in-memory session state (lilith.platform.session_state). It is never saved to the database.
  • Hardware Support & Detection Scope Statement:
    • Supported Scope at Launch: Hardware detection and acceleration are verified and actively supported only for NVIDIA GPUs (on Windows/Linux via nvidia-smi) and Apple Silicon (on macOS via unified memory size query).
    • Other Hardware (AMD, Intel Arc, etc.): Detection for non-NVIDIA/non-Apple Silicon GPUs is not implemented at launch; such hardware will return no VRAM during detection and implicitly fallback to Tier 0 (CPU-only/Cloud). Acceleration on these platforms is "best effort, unverified" and unsupported in v6 v1 due to developer QA hardware constraints.
    • Post-Build Verification Checklist: As Apple Silicon (M1/M2/M3) unified memory graphics acceleration via Metal has not yet been physically tested by the sole developer, a mandatory post-first-build checklist item requires verifying Whisper/Kokoro Metal performance on an actual M1 machine before the official release.
