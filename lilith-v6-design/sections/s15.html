Tools are startup-discovered YAML contracts with explicit mode eligibility and narrative templates that let artifact work acknowledge immediately, run in the background, and hand back results cleanly.

  • Definition format: lilith/tools/*.yaml, parsed with PyYAML==6.0.3, requiring name, description, JSON-schema-like parameters, mode, and narratives.
  • YAML safety rule: All tool contracts and skill frontmatter are untrusted input and MUST be parsed with yaml.safe_load only. yaml.load, yaml.full_load, custom YAML object constructors, or any parser mode that can instantiate Python objects are prohibited for lilith/tools/*.yaml, SKILL.md frontmatter, packaged manifests, and user-enrolled manifests. Skill files are additionally size-gated before parsing: a SKILL.md whose raw file size exceeds SKILL_MAX_INJECTED_BYTES (§13) is rejected at CLI enrollment and quarantined at startup manifest verification without ever reaching yaml.safe_load — the size check runs on raw bytes, ahead of any parser.
  • Mode enum: conversational_only, artifact_only, or both; router rejects unavailable tools before any LLM call.
  • Narrative keys: acknowledge, bridge, handoff, and failure are mandatory for every artifact-capable tool.
  • Acknowledge: Artifact tools fire narratives.acknowledge to TTS within <200 ms after router classification.
  • Bridge: Default bridge interval is 8 s; v6 v1 uses static templates such as Still working on that..., with UCL-adaptive timing deferred.
  • Handoff: v6 v1 handoff is deterministic template fill from the typed tool result; PERS-2 narration is not in the first implementation.
  • Telemetry: Emit tool.call.start (tool_name, mode), tool.call.complete (duration_ms, success), tool.narrative.ack (tool_name), and tool.narrative.handoff (tool_name, artifact_id).
name: contact_lookup
description: Look up a person in contacts_db L2 context.
mode: artifact_only
parameters:
  type: object
  required: [name]
  properties:
    name: {type: string, minLength: 1}
narratives:
  acknowledge: "I'll look that person up."
  bridge: "Still checking the contact record..."
  handoff: "{display_name}: {summary}"
  failure: "I couldn't find a matching contact."
