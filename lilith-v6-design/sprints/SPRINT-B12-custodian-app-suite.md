### [B12-01] Google OAuth system-browser flow and keyring token storage
**Type:** [IMPLEMENT]. **Law:** s19 (OAuth flow, Client packages, Scopes, Token storage, Read-only enforcement), s02 (credentials table, Credential Update & Revocation), standards (read-only, no secrets in logs).  
**Depends on:** BD-053, BD-054, BD-058.  
**What to build:** `lilith/platform/google_auth.py`. A `GoogleAuth` class: `connect()` runs `InstalledAppFlow.run_local_server(host="127.0.0.1", port=0)` with the browser opener injectable (system browser only, never a WebView), PKCE on, `access_type=offline`, and a `SCOPES` constant that is exactly the tuple of `calendar.readonly` and `contacts.readonly` (a test asserts equality with that literal pair). On success the refresh token is stored with `keyring.set_secret("google_oauth_refresh_token", ...)`; the access token is cached in process memory only and refreshed on demand. `credentials()` returns usable credentials or raises a typed error when no token exists; `disconnect()` deletes the keychain entry, drops the memory cache and best-effort revokes at Google's revoke endpoint (failure to revoke never leaves the local token behind). Append `GoogleNotConfigured`, `GoogleAuthFailed`, `GoogleNotConnected` to `lilith/errors.py` with fixed messages raised `from None` (no provider text). Events: `sync.google.connected` and `sync.google.disconnected` (no token material). No sync, no UI.  
**Docs:** create `docs/architecture/components/google-sync.md` (auth section, scope list, token lifecycle), update `docs/CHANGELOG.md`.  
**Acceptance:** tests against a loopback fake authorization/token server and an injected browser opener: happy path stores only the refresh token in a fake keyring backend; the token appears in no log record, event payload, config or env; scopes equal the read-only pair exactly (can-fail: adding a write scope turns the test red); user denies consent -> typed error, nothing stored; `disconnect()` removes the secret even when revoke fails; missing client config -> `GoogleNotConfigured`. A real Google consent run is developer-only.
